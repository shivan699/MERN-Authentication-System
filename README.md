# MERN Authentication System

## Features
- User Registration
- Email Verification OTP
- JWT Authentication
- Refresh Token
- Forgot Password
- Reset Password
- Email OTP Login
- Phone OTP Login
- Protected Routes
- Rate Limiting
- Input Validation

## Tech Stack
- React
- Node.js
- Express
- MongoDB
- JWT
- Nodemailer
- Twilio

## Installation

Backend

cd backend
npm install
npm run dev

Frontend

cd auth-frontend
npm install
npm run dev

## Environment Variables

Create .env files.

Backend

PORT=
MONGO_URI=
JWT_SECRET=
JWT_REFRESH_SECRET=
EMAIL_USER=
EMAIL_PASS=
TWILIO_ACCOUNT_SID=
TWILIO_AUTH_TOKEN=
TWILIO_PHONE_NUMBER=

Frontend

VITE_API_URL=http://localhost:5000/api
